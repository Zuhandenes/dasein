# Сайт-визитка преподавателя философии Андрея Лемана

## 📋 Описание
Сайт-визитка с возможностью записи на консультации. Включает:
- Краткое био и информацию об образовании
- Список услуг (философское консультирование, преподавание, др.)
- Подробное описание услуг
- Подтверждение экспертизы
- Отзывы в формате «До/После»
- Форму записи на консультацию

## 🚀 Быстрый старт

### Вариант 1: Node.js сервер (рекомендуется, работает форма записи)
```bash
# Установка зависимостей (не требуется, так как нет внешних зависимостей)
# npm install

# Запуск сервера
npm start

# Откройте в браузере: http://localhost:3000
```

Сервер обрабатывает:
- Статические файлы (HTML, CSS, JS, изображения)
- POST запросы на `/api/book` для записи на консультации
- Заявки сохраняются в `bookings.json` и логируются в консоль

### Вариант 2: Простой просмотр без сервера
Просто откройте файл `index.html` в любом браузере. Форма записи не будет работать (требуется сервер).

## 🔧 Функционал бэкенда

### API endpoints
- `GET /` - Главная страница
- `GET /css/main.css` - Стили
- `GET /js/app.js` - JavaScript
- `POST /api/book` - Отправка заявки на консультацию

### Формат заявки (POST /api/book)
```json
{
  "name": "Имя клиента",
  "contact": "Email или телефон",
  "service": "Название услуги",
  "message": "Комментарий"
}
```

Заявки сохраняются в файл `bookings.json` и логируются в консоль.

## 🌐 Деплой

### На Vercel
1. Установите CLI: `npm i -g vercel`
2. Выполните: `vercel deploy`
3. Следуйте инструкциям
4. **Важно**: Для работы формы записи потребуется настроить Serverless Functions или использовать внешний API

### На Netlify
1. Перетащите папку проекта на [netlify.com/drop](https://app.netlify.com/drop)
2. Или используйте CLI: `npm install -g netlify-cli && netlify deploy`
3. **Для формы записи**: подключите Netlify Forms или используйте внешний сервис

### На Render/Railway (рекомендуется для полной функциональности)
1. Подключите репозиторий GitHub
2. Укажите команду старта: `node server.js`
3. Порт настроится автоматически через переменную окружения PORT
4. Заявки будут сохраняться и логироваться

### На обычном хостинге с Node.js
Загрузите все файлы через FTP. Запустите сервер командой `node server.js`.

### Альтернатива: Статический хостинг + внешний API
Если используете статический хостинг (GitHub Pages, Netlify без сервера):
- Интегрируйте форму с EmailJS, Formspree или Google Forms
- Замените обработчик формы в `js/app.js`

## 📝 Примечания
- Для добавления фотографии поместите файл в папку `images/` и обновите путь в HTML
- В production замените заглушки ссылок на реальные соцсети
- Для отправки заявок на email интегрируйте с сервисом вроде EmailJS или SendGrid
